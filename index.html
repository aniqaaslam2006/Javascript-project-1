### Question 1: First and Last Name

Create two variables: `firstName` and `lastName`. Store your first and last name in them and print your full name.

### Question 2: Arithmetic Operations

Create three variables: `num1`, `num2`, and `num3`. Perform the following operations using all three values: - Addition - Subtraction - Multiplication - Division Display the result of each operation.

### Question 3: Temperature Checker

Take the temperature from the user. - If the temperature is 0°C or below, print `"Freezing"`. - Otherwise, print `"Not freezing"`.

### Question 4: Age Category

Take the user's age and display the appropriate category: - 0–12: Child - 13–19: Teenager - 20–59: Adult - 60 and above: Senior Citizen

### Question 5: Electricity Bill Calculator

Take the number of electricity units consumed and calculate the bill using these rates: - First 100 units: Rs. 10 per unit - Next 100 units: Rs. 15 per unit - Above 200 units: Rs. 20 per unit Calculate the bill using cumulative rates. For example, the first 100 units are charged at Rs. 10 each, and only the units above 100 are charged at the next rate.

### Question 6: Traffic Light

Take a traffic light color as input. - Red: `"Stop"` - Yellow: `"Ready"` - Green: `"Go"` - Any other color: `"Invalid Color"`

### Question 7: Pocket Money Checker

Take the amount of pocket money. - If it is greater than Rs. 500, print `"You can buy a gift"`. - Otherwise, print `"Save your money"`.

### Question 8: Free Delivery Checker

Take the total shopping amount. - If it is Rs. 2,000 or more, print `"Free Delivery"`. - Otherwise, print `"Delivery Charges Apply"`.

## Submission Instructions

- Write JavaScript code for all 8 questions. - Use variables and appropriate arithmetic operators. - Use `if`, `else if`, and `else` where required. - Take user input using `prompt()` where needed. - Display the output using `console.log()`.
